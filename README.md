# Monte Carlo Simulation Experiment

📌 Project Overview
This project demonstrates the use of Monte Carlo simulation techniques to estimate probabilities through repeated random sampling. The objective was to apply probability concepts learned in the IIT Madras BS Data Science program.

📚 Key Concepts Applied
- Probability Theory
- Random Sampling
- Monte Carlo Simulation
- Experimental Probability
- Statistical Interpretation

📊 Key Analysis Performed
- Design of probability experiment using random trials
- Repeated simulations to estimate event probabilities
- Comparison of theoretical and experimental probability
- Visualization of simulation results

🛠 Tools Used
- Python
- Google Colab
